# Historical engineering records

This directory preserves implementation handoffs, former status summaries and
qualification evidence for traceability. Dates, old pins, local paths and open
items describe the recorded work, not current product requirements or a release
roadmap. These records are excluded from the installed documentation and shared
contract payload.

For current operation and integration, use [Operator documentation](../../README.md),
[Harness integration](../../docs/HARNESS_INTEGRATION.md) and the
[release contract lock](../../release/contract-lock.json). Qualification records
establish only the combinations and checks they actually exercised.
